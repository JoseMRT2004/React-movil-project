## Enunciado

Esta semana nos sumergimos en el mundo de IONIC o React. La tarea consiste en crear una
aplicación con varias funcionalidades interesantes: una oportunidad para poner en práctica las
habilidades y la creatividad.

### Crear una aplicación con menú

La aplicación debe incluir un menú con las siguientes opciones:

| # | Página | Qué debe mostrar |
| :-: | --- | --- |
| a | **Página Inicial** | Datos personales: foto 2x2, nombre, apellido y correo electrónico. |
| b | **Sumadora** | Sumar dos números y mostrar el resultado. |
| c | **Traductor de Números a Letras** | Ingresar un número del 1 al 1000 y mostrarlo en letras en español. **No se permite el uso de APIs**; la pérdida de puntos aplicará si se detecta su uso. |
| d | **Tabla de Multiplicar** | Aceptar un número y mostrar su tabla de multiplicar hasta el 13. |
| e | **Experiencia Personal** | Un video de YouTube explicando la experiencia al realizar la tarea. En el video debe aparecer el rostro en una esquina mientras se explica, y no debe durar más de 5 minutos. |

### Documentación y entrega

Subir la carpeta del proyecto a un repositorio e incluir el enlace en un documento PDF, junto a un
código QR para descargarlo.

## Cómo entregar

Crear un documento PDF que incluya:

- Nombre y apellido
- Matrícula
- Foto 2x2
- Enlace y código QR al repositorio del código
- Enlace y código QR al video de experiencia personal, donde debes aparecer
