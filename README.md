# Tarea 3 - Explorando IONIC o React con un Proyecto Creativo

## Requisitos

Una aplicación con menú y cinco páginas:

- **a. Página Inicial** — datos personales: foto 2x2, nombre, apellido y correo electrónico.
- **b. Sumadora** — sumar dos números y mostrar el resultado.
- **c. Traductor de Números a Letras** — ingresar un número del 1 al 1000 y mostrarlo en letras en español. **No se permite el uso de APIs.**
- **d. Tabla de Multiplicar** — aceptar un número y mostrar su tabla de multiplicar hasta el 13.
- **e. Experiencia Personal** — un video de YouTube explicando la experiencia al realizar la tarea, con el rostro en una esquina y sin superar los 5 minutos.

## Entrega

Subir la carpeta del proyecto a un repositorio y entregar un documento PDF con:

- Nombre y apellido
- Matrícula
- Foto 2x2
- Enlace y código QR al repositorio del código
- Enlace y código QR al video, donde debes aparecer
